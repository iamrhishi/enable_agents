# Workflow Tasks - Lightweight Implementation Plan

## Overview
Add task/checklist functionality to workflow stages. Tasks can be auto-generated by agents or created manually by users. Stage completion is blocked until required tasks are done.

## Database Model

```python
class WorkflowTask(db.Model):
    __tablename__ = "workflow_tasks"

    id = db.Column(db.Integer, primary_key=True)
    task_id = db.Column(db.String(36), unique=True, index=True)  # UUID
    instance_id = db.Column(db.String(36), ForeignKey("workflow_instances.instance_id"))
    stage_id = db.Column(db.String(100))  # e.g., "requirement_capture"

    title = db.Column(db.String(255), nullable=False)
    description = db.Column(db.Text, nullable=True)

    assigned_to = db.Column(db.String(255), nullable=True)  # user email
    status = db.Column(db.String(20), default="pending")  # pending, in_progress, done
    is_required = db.Column(db.Boolean, default=True)  # blocks stage completion
    source = db.Column(db.String(20), default="manual")  # manual, agent

    created_by = db.Column(db.String(255))
    created_at = db.Column(db.DateTime, default=datetime.utcnow)
    completed_at = db.Column(db.DateTime, nullable=True)
    completed_by = db.Column(db.String(255), nullable=True)
```

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/workflows/instances/{id}/tasks` | List all tasks for workflow |
| GET | `/workflows/instances/{id}/stages/{stage}/tasks` | List tasks for specific stage |
| POST | `/workflows/instances/{id}/tasks` | Create a task |
| PATCH | `/workflows/instances/{id}/tasks/{task_id}` | Update task (status, assignee, etc.) |
| DELETE | `/workflows/instances/{id}/tasks/{task_id}` | Delete a task |

## Stage Completion Check

Before allowing stage completion:
1. Query all tasks where `stage_id = current_stage` AND `is_required = True`
2. Check if all have `status = 'done'`
3. If not complete → return error with list of pending tasks
4. If complete → proceed with stage completion

## Notifications (Phase 2)

Use existing notification system or simple approach:
- On task assignment → notify assignee
- On task completion → notify stage owner
- On all required tasks done → notify workflow owner

## Agent-Generated Tasks

When agent runs a stage, it can return suggested tasks:
```json
{
  "outputs": {...},
  "suggested_tasks": [
    {"title": "Review supplier quotes", "description": "Compare pricing from 3 vendors"},
    {"title": "Verify certifications", "description": "Check ISO compliance"}
  ]
}
```

These appear as "suggested" and user can accept/dismiss them.

## Permission Check

Use existing TeamMember roles:
- **owner/admin**: Create, edit, delete any task; assign to anyone
- **member**: Create tasks; edit own tasks; mark any task done
- **viewer**: View only
